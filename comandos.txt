# COMANDOS DE DESPLIEGUE (VPS)

Ejecuta estos comandos en orden dentro de la carpeta del proyecto en la VPS para actualizar el sistema de forma segura:

1. Descargar los cambios del código:
git pull

2. Reconstruir e iniciar solo los contenedores modificados (Frontend y Backend):
docker compose up -d --build frontend backend
(Nota: Esto evita reiniciar la Base de Datos y n8n, previniendo cortes en las automatizaciones activas de tu cliente).

3. Limpiar imágenes obsoletas para liberar espacio:
docker image prune -f

4. Verificar que todo esté corriendo correctamente:
docker compose ps
